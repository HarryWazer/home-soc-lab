# Home SOC Lab — Εντοπισμός Επιθέσεων & Απόκριση σε Περιστατικά
Ένα αυτοστηριζόμενο εικονικό Security Operations Center lab που ενσωματώνει τηλεμετρία Windows endpoint με ανίχνευση μέσω Wazuh SIEM, προσομοιώνοντας τέσσερις πραγματικές τεχνικές επίθεσης και τεκμηριώνοντας την καθεμία ως πλήρη υπόθεση απόκρισης σε περιστατικό, αντιστοιχισμένη στο MITRE ATT&CK.
## Επισκόπηση
Αυτό το project προσομοιώνει ένα μικρό εταιρικό περιβάλλον με έναν επιτιθέμενο και έναν αμυνόμενο να λειτουργούν παράλληλα. Εκτελέστηκαν τέσσερα σενάρια επίθεσης, εντοπίστηκαν (ή σκόπιμα δεν εντοπίστηκαν, για τη μελέτη κενών ορατότητας), αναλύθηκαν και τεκμηριώθηκαν ως επίσημα incident reports — με τον τρόπο που θα το έκανε ένας junior SOC analyst σε πραγματική διερεύνηση.

## Τεχνολογίες
- **SIEM/XDR:** Wazuh 4.14.8 (manager, indexer, dashboard)
- **Θύμα:** Windows 11 Enterprise Evaluation, Wazuh agent
- **Επιτιθέμενος:** Kali Linux (Hydra, Nmap, xfreerdp)
- **Virtualization:** Oracle VirtualBox, Host-only networking

| # | Σενάριο | Τεχνική | Εντοπίστηκε; | Report |
|---|---|---|---|---|
| 1 | RDP Brute Force | T1110.001 — Password Guessing | ✅ Ναι | [INC-001](incidents/INC-001_el.md) |
| 2 | Ύποπτο PowerShell | T1057, T1059.001, T1003.001 | ⚠️ Μερικώς | [INC-002](incidents/INC-002_el.md) |
| 3 | Επιμονή (Scheduled Task) | T1053.005 | ✅ Ναι | [INC-003](incidents/INC-003_el.md) |
| 4 | Αναγνώριση Δικτύου | T1595.001, T1046, T1018 | ❌ Όχι (τεκμηριωμένο κενό) | [INC-004](incidents/INC-004_el.md) |
Κάθε report περιλαμβάνει: πηγή εντοπισμού, χρονολόγιο, ακατέργαστα αποδεικτικά στοιχεία, ανάλυση βασικής αιτίας, αντιστοίχιση MITRE ATT&CK, και προτεινόμενες ενέργειες αποκατάστασης — όχι απλώς "έτρεξα ένα εργαλείο, είδα ένα alert".
Περιλαμβάνονται επίσης αγγλικές εκδόσεις όλων των τεσσάρων reports (`INC-00X.md`).
## Βασικά Ευρήματα
- **Οι αδύναμοι κωδικοί νικούν την άμυνα σε βάθος.** Ένας κωδικός ίδιος με το username έκανε την επίθεση brute force στο INC-001 τετριμμένη, παρά το ότι το SIEM κατέγραφε σωστά.
- **Η απόκρυψη με Base64 δεν νικά το PowerShell Script Block Logging** — τα Windows αποκωδικοποιούν και καταγράφουν την τελική εντολή ανεξάρτητα από την κωδικοποίηση (INC-002).
- **Δεν είναι κάθε alert σε ένα χρονικό παράθυρο προερχόμενο από επιτιθέμενο.** Το ίδιο το module SCA του Wazuh παρήγαγε τηλεμετρία PowerShell που συνέπεσε με το παράθυρο δοκιμής στο INC-002 και χρειάστηκε να εξαιρεθεί κατά το triage — ένα ρεαλιστικό μάθημα false-positive.
- **Τα κενά ορατότητας έχουν διαφορετικές βασικές αιτίες, και διαφορετικές λύσεις.** Τα INC-002 και INC-003 μπλοκαρίστηκαν από *απενεργοποιημένες ρυθμίσεις audit των Windows* (διορθώσιμο μέσω ρύθμισης). Το INC-004 μπλοκαρίστηκε από *κενό decoder στο Wazuh* για τη native μορφή του Windows Firewall log (δεν διορθώνεται μόνο με ρύθμιση — απαιτεί ανάπτυξη custom κανόνα ή διαφορετική προσέγγιση παρακολούθησης).
- **Η συλλογή δεν είναι εντοπισμός.** Στο INC-004, ο Wazuh agent διάβαζε ενεργά το σχετικό αρχείο log από άκρη σε άκρη, κι όμως δεν παρήχθη κανένα alert — μια υπενθύμιση να επαληθεύεις ολόκληρο τον αγωγό επεξεργασίας (agent → server → decoder → rule → index) πριν εμπιστευτείς έναν μηχανισμό παρακολούθησης.
Δες το [mitre/attack-mapping_el.md](mitre/attack-mapping_el.md) για την πλήρη συγκεντρωτική σύνοψη κάλυψης MITRE ATT&CK σε όλα τα τέσσερα σενάρια.
